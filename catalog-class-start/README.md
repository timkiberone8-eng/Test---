# Старт к занятию 11

Этот проект открывается на текстовом каталоге занятия 10. Дальше работаем по [занятию 11](https://github.com/timkiberone8-eng/python-kiber/tree/main/session11).

1. Откройте папку `catalog-class-start` в VS Code. Рядом с `START.cmd` лежит `manage.py`.
2. Дважды нажмите `START.cmd`. При первом запуске в окне появятся логин `rehearsal` и случайный пароль для админки. Сохраните пароль до конца занятия.
3. Откройте [главную](http://127.0.0.1:8011/) и [админку товаров](http://127.0.0.1:8011/admin/catalog/product/). В админке измените цену ручки с 30 до 35 ₽ и найдите новую цену на главной. Верните её к 30 ₽, чтобы сверяться с примерами.

Для запуска нужны Python и Django в том же окружении. Если Django ещё нет, из папки с `manage.py` выполните `python -m pip install -r requirements.txt`. Если забыли пароль, выполните `python manage.py changepassword rehearsal`.

`START.cmd` применяет миграции в локальной SQLite, добавляет три учебных товара при первом запуске и поднимает сервер. При повторном запуске сохраняются созданные товары и пароль.
